# SecondSelf
SecondSelf is a personal AI second brain. It captures notes, links, and files; organizes them into PARA-style Markdown notes; discovers related notes with local embeddings; visualizes the resulting wiki; and answers questions from those notes.
## Project Status
The project is currently in Phase 0, with the repository structure, configuration, dependency list, and environment template in place.
## Repository Layout
The repository is organized into the following directories: raw, wiki, data, and docs.
## Setup and Configuration
The project requires Python 3.10 or later, a virtual environment, and the installation of dependencies. The configuration is managed through the config.py file and the .env file.
