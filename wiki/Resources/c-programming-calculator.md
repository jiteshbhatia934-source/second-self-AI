# C Program Calculator
## Purpose
The program is a calculator that allows users to choose from a menu of operations: addition, subtraction, multiplication, division, and remainder.
## Code Explanation
### Libraries
* `stdio.h`: input/output functions such as `printf` and `scanf`.
* `stdlib.h`: used for `exit(0)` to terminate the program.
### Variables
* `a` and `b`: store user input numbers.
* `res`: store calculation result.
* `ch`: store user's choice of operation.
### Menu and User Input
* Print menu options.
* Get user's choice of operation using `scanf`.
### Calculation and Output
* Use `switch` statement to perform chosen operation.
* Print result of calculation.
## Example Execution
* Run program, choose operation, input numbers, and view result.
