The project is organized as a root-level Python package with three child modules: `lib_core` provides shared models, filesystem storage, text extraction, vector embeddings, and Groq LLM integration; `cli_scripts` implements the command-line pipeline (capture → classify → link → graph build → Streamlit preview with RAG); `docs` holds architecture and implementation plans. All children consume configuration through the root `config.py`, which loads `.env` variables (GROQ_API_KEY, RAW_DIR, WIKI_DIR, DATA_DIR, GRAPH_PATH, SIMILARITY_THRESHOLD, TOP_K_RETRIEVAL, EMBEDDING_MODEL) and enforces validation at import time. The data flow follows a fixed directory contract: `raw/` holds immutable captures, `wiki/` stores PARA-organized Markdown (Projects/Areas/Resources/Archives), and `data/` contains regenerable embedding cache and indexes, with `graph.json` as the intermediate artifact consumed by the Streamlit graph preview.
