Each script is an independent CLI entry point exposing a `main()` function; `pipeline.py` is the orchestrator that dispatches to `classify`, `link`, and `build_graph` via lazy imports. Data flows through three persistent directories defined in `config`: `raw/` (JSON captures), `wiki/` (PARA-organized Markdown with YAML front matter), and `graph.json` (exported by `build_graph`). `capture.py` uses Typer for its subcommands (`note`, `link`, `file`) and writes JSON records to `raw/`. `classify.py` reads `raw/*.json`, optionally calls Groq for AI classification with local heuristic fallback, and writes normalized Markdown with YAML front matter into `wiki/{Para}/`. `link.py` consumes `lib.embeddings.build_note_embeddings` to compute cosine similarity between notes and injects `[[wikilink]]` references into a `## Related` section. `build_graph.py` reads notes via `lib.storage.read_wiki_notes()`, resolves wikilinks against a target lookup (id/slug/title/filename), and atomically writes `graph.json` with a `meta` block. `ask.py` implements RAG: loads embeddings, scores notes by cosine similarity plus a lexical bonus, and synthesizes answers via `lib.llm.synthesize_answer`. `graph_preview.py` is a Streamlit app that reuses `build_graph`, `classify`, `capture`, and `ask` modules directly, inlining `graph.json` into `static/graph.html` for vis-network rendering. Dependency direction is one-way: UI → pipeline scripts → `lib.*` (storage, embeddings, models, llm) → filesystem.
