Run the full pipeline as `python pipeline.py process`; individual stages are `python pipeline.py classify` and `python pipeline.py link`. The Streamlit preview runs via `streamlit run graph_preview.py`. Optional AI features require setting `GROQ_API_KEY` in the environment or `.env` file; without it, `classify.py` falls back to local heuristics and `ask.py` returns retrieved sources without a synthesized answer.
