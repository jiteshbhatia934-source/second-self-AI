Setup requires creating a venv, installing pinned dependencies from `requirements.txt`, obtaining a Groq API key stored in `.env`, and running the pipeline sequentially: `python capture.py note/link/file`, `python classify.py [--force]`, `python link.py`, `python build_graph.py`, then `streamlit run app.py`. A convenience `python pipeline.py --steps classify,link,graph` is planned to orchestrate Weeks 2–3.
