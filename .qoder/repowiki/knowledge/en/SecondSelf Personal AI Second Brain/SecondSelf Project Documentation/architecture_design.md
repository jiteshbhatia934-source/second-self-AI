The docs define a modular monolith built around four sequential pipeline stages (capture → classify → link → graph → ask) plus a Streamlit presentation layer. Data flows through file-system artifacts: `raw/` append-only JSON envelopes, `wiki/{Projects|Areas|Resources|Archives}/` Markdown notes with YAML front matter, `data/embeddings.pkl` for the embedding cache, and `graph.json` as the UI contract. Each stage is a standalone Python script (`capture.py`, `classify.py`, `link.py`, `build_graph.py`, `ask.py`) orchestrated by an optional `pipeline.py`, all consumed by a single `app.py` Streamlit entry point. Configuration is centralized in `config.py` loaded from `.env`. The architecture explicitly rejects microservices and databases for MVP, keeping everything Git-friendly and human-readable so the brain survives without the app.
